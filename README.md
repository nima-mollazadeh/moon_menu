# MOON — منوی دیجیتال فست‌فود

یک وب‌سایت منوی فارسی و راست‌چین، ساخته‌شده با HTML، CSS و JavaScript ساده؛ بدون نیاز به Node.js یا نصب پکیج.

## اجرای پروژه

1. فایل ZIP را استخراج کن.
2. فایل `index.html` را در مرورگر باز کن. برای بهترین تجربه می‌توانی از افزونه‌ی Live Server در VS Code استفاده کنی، اما اجباری نیست.
3. برای انتشار، هر پنج فایل پروژه را روی هاست استاتیک یا فضای میزبانی وب آپلود کن.

## قابلیت‌ها

- منوی واکنش‌گرا با دسته‌بندی‌های قابل پیمایش و نوار دسته‌بندی چسبان
- جست‌وجوی نام غذا و دسته‌بندی
- کارت‌های غذا با قیمت و دکمه‌ی افزودن
- تنظیم سایز و افزودنی‌ها برای غذاهای قابل سفارشی‌سازی
- سبد خرید با افزایش/کاهش تعداد، حذف آیتم و محاسبه‌ی جمع سفارش
- ذخیره‌ی سبد در مرورگر با `localStorage`
- فرم سفارش بدون ثبت‌نام، انتخاب ارسال یا تحویل حضوری و اعتبارسنجی ورودی‌ها
- ساخت متن سفارش و بازکردن واتساپ، پس از وارد کردن شماره‌ی رستوران
- متن شفاف در حالت نمایشی؛ بدون ادعای پرداخت یا ثبت سفارش واقعی
- اطلاعات تماس، آدرس، لینک شبکه‌های اجتماعی و هزینه ارسال در تنظیمات جداگانه

## تنظیم اطلاعات رستوران

فایل `config.js` را باز کن:

- `whatsappNumber`: شماره واتساپ با کد کشور، فقط عدد (برای نمونه‌ی قالب ایران از `98` شروع می‌شود؛ شماره‌ی واقعی را خودت وارد کن).
- `phoneNumber`: تلفن رستوران.
- `instagramUrl` و `telegramUrl`: لینک کامل شبکه‌های اجتماعی.
- `address` و `mapUrl`: آدرس و لینک نقشه.
- `openingHours`: ساعت کاری.
- `deliveryFee`: هزینه ارسال بر حسب تومان. تا زمانی که مقدار `null` است، هزینه ارسال «پس از تأیید» نمایش داده می‌شود.

برای جلوگیری از نمایش اطلاعات نادرست، مقادیر خالی به‌عنوان اطلاعات تأییدنشده باقی گذاشته شده‌اند.

## ویرایش منو و قیمت

فایل `menu-data.js` منبع اصلی دسته‌ها و محصولات است. محصولات فعلی داده‌های نمونه‌اند، نه منوی تأییدشده‌ی رستوران. قیمت‌ها را بر حسب تومان و در فیلد `price` ویرایش کن. هر محصول شامل `id`, `name`, `desc`, `price`, `category`, `image`, `alt` است؛ `popular` و `badge` اختیاری هستند. گروه‌های `customizations` برای تنظیم سایز، سس یا افزودنی‌اند.

## حریم فنی و محدودیت‌ها

- پرداخت آنلاین، موجودی انبار، پنل مدیریت، ذخیره سفارش در سرور و تأیید خودکار سفارش پیاده‌سازی نشده‌اند.
- ارسال از واتساپ با بازکردن متن آماده انجام می‌شود؛ مشتری باید پیام را خودش ارسال کند و رستوران سفارش را تأیید کند.
- تصاویر غذا و فونت‌ها از منابع بیرونی بارگذاری می‌شوند و برای نمایش آن‌ها اتصال اینترنت لازم است.
- قبل از استفاده تجاری، منو، قیمت‌ها، حق استفاده از تصاویر، اطلاعات تماس و روش ثبت سفارش را با اطلاعات واقعی خودتان جایگزین و روی موبایل و دسکتاپ آزمایش کنید.


### تصاویر غذا
تصاویر غذا اکنون داخل پوشه `assets/images/` قرار دارند و برای نمایش به اینترنت یا سرویس تصاویر خارجی وابسته نیستند. برای تعویض عکس هر محصول، مسیر `image` همان محصول را در `menu-data.js` به فایل دیگری از همین پوشه تغییر بده. تصویر بخش معرفی در `index.html` به `assets/images/hero-burger.jpg` اشاره می‌کند.


## آخرین اصلاحات رابط کاربری

- دسته‌بندی‌های منو به‌صورت کارت‌های تصویری با آیکون SVG و نام فارسی در زیر آیکون نمایش داده می‌شوند.
- نمایش قیمت محصولات از فونت خواناتر و قالب جداگانه برای عدد و واحد «تومان» استفاده می‌کند.
- بلوک سه‌گانه معرفی ویژگی‌ها و یادداشت «انتخاب‌های خوب همین دور و برن» حذف شده‌اند.
